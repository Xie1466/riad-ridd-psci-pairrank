# Third-party software

- Python 3.12.3.
- NumPy 1.26.4: arrays and deterministic numerical linear algebra.
- SciPy 1.11.4: Spearman and Kendall tau-b metrics.
- Matplotlib 3.6.3: computational check figures.
- PyYAML 6.0.1: historical trajectory-extraction configuration parsing (not needed by quick reproduction).
- GROMACS 2025.2 was used in the historical trajectory-to-descriptor lineage. Its binary is not redistributed. Full reproduction requires a compatible GROMACS installation and a separately deposited exact trajectory/reference set.

The release contains no copied third-party source code beyond ordinary imports. Literature metadata must retain article citations and source-specific rights.
