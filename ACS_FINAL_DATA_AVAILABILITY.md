# Data Availability

The compact software archive identified by the stable concept DOI https://doi.org/10.5281/zenodo.22638943 and the corresponding GitHub release contain the minimal sufficient data supporting the computational analyses. Literature V3.2 includes 19 studies, 20 systems, 91 constructs, 102 phenotype records and 381 validated matched pairs; 377 are eligible non-ties and four are ties. Internal16 includes four enzyme systems, 16 topologies and 24 within-system pair relations.

Deposited tables include experimental endpoint summaries, MD quality-control classifications, the exact PSCI feature dictionary, the frozen 16-topology PSCI matrix, literature-prior inputs and overlap exclusions, all 24 frozen M2 out-of-fold predictions, M0–M3 comparisons, Figure 1–6 source tables, provenance records and SHA-256 manifests. Missing replicate values, SDs and SEMs were not reconstructed. Production trajectories are not included, so full trajectory-to-feature reproduction is `NOT_AVAILABLE`.
